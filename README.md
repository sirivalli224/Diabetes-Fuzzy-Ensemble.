Diabetes Prediction Using Fuzzy Ensemble Learning

Overview

This project demonstrates diabetes prediction using a machine learning ensemble combined with fuzzy logic.

Models Used

- Support Vector Machine (SVM)
- Artificial Neural Network (ANN)
- Random Forest
- Gradient Boosting
- Fuzzy logic for combining model predictions

Dataset

UCI Early Stage Diabetes Risk Prediction Dataset (520 instances, 16 features).

Dataset: https://archive.ics.uci.edu/dataset/529/early

Implementation

The notebook covers data preprocessing, model training, fuzzy fusion, evaluation metrics, and visualization.

Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Scikit-fuzzy
- Matplotlib

Disclaimer

This is an educational case study and is not intended for medical diagnosis.
